# 阶段二：执行规范 (Code Act)

执行经过确认的规划。
不要做多余重构。
先说做什么，再说怎么做。

## 输出结构

### 1. 要做什么 (What to do)
- **目标文件**：`path/to/target/file.ext`
- **目标锚点**：函数名、类名或特征代码行。
- **改动目的**：一句话说明此处解决什么问题。

### 2. 怎么做 (How to do)
- **编辑操作**：调用工具完成代码替换。
- **验证命令**：执行编译或测试命令：
  ```bash
  <测试或构建命令>
  ```

* **验证结果**：说明命令是否通过。

> 代码修改完成，测试通过。请检查 Git 差异（Git Diff）。
